# 🔬 REVERSE ENGINEERING PIPELINE — Systematic AST Disassembly & Modernization

> 🔴 **ABSOLUTE LAW:** Never attempt to refactor legacy code without completing 100% AST inventory, mapping causal data-flow DAGs from ingestion to sinks, and applying the Tri-Axis Polarity Matrix. Speculative edits and blind deletion are strictly prohibited.

---

## 1. ARCHAEOLOGICAL AUDIT WORKFLOW
1. **Inventory Scan:** Catalog 100% of modules, classes, functions, global singletons, and imports.
2. **Interface Contract Extraction:** Document inputs, outputs, side effects, invariants, and hidden exceptions for each component.
3. **Seam Identification:** Isolate decoupled boundaries where modern high-performance modules can replace legacy spaghetti (Strangler Fig pattern).
4. **Regression Harness:** Author minimal reproducible unit tests capturing exact legacy behavior before rewriting.

---

## 2. THE TRI-AXIS POLARITY ANALYSIS MATRIX (DISSECAÇÃO POLAR UNIVERSAL)
Before refactoring any mathematical engine, critical algorithm, or legacy subsystem, execute the Tri-Axis Polarity audit:

`
                      ▲ TOPO (O Que Falta / Inovação / Limites Físicos)
                      │ • Fatores ocultos e dimensões não exploradas
                      │ • Acelerações modernas (SIMD, AVX, cache locality, concorrência)
                      │ • Otimizações assintóticas e limites teóricos ideais
                      │
                      │
  ◄───────────────────┼───────────────────►
  CENTRO (Estado Real)│
  • Desmontagem fria da AST
  • Baseline de consumo (latência, memória, throughput)
  • Fórmulas e algoritmos exatos em execução
                      │
                      │
                      │ • Lógicas pobres e aproximações sem rigor
                      │ • Lookahead bias, vazamento de dados, loops lentos
                      │ • Definição formal do contrato substituto
                      ▼ FUNDO (O Que Cancelar & Substituir / Patologias)
`

### Protocolo de Aplicação dos 3 Eixos:
- 🔵 **CENTRO (O Que Temos / Estado Real):**
  * Dissecção completa da AST e inventário algorítmico exato.
  * Baseline empírico de latência, consumo de memória e throughput.
- 🟢 **TOPO (O Que Falta / Inovação / Limites Físicos):**
  * Inovações arquiteturais, paralelismo e aceleração de hardware.
  * Extensão de dimensões de análise e modelos de maior fidelidade.
- 🔴 **FUNDO (O Que Cancelar & Substituir / Patologias):**
  * Eliminação de dead code, dependências circulares e números mágicos.
  * Substituição de estruturas frágeis por contratos tipados e verificados formalmente.

---

## 3. MODERNIZATION TRANSFORMATION
- Legacy Imperative / Slow Loops -> Vectorized, Parallel, Async, or Hardware-Accelerated Pipelines.
- Implicit State / Untyped Dictionaries -> Strict Typed Dataclasses / Formal Contract Interfaces.
- Monoliths -> Decoupled Clean Architecture with isolated boundaries.
- Verification Gate: Exit code 0, 100% test pass, zero regressions, measurable performance multiplier.
