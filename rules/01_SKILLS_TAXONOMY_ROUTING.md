# SKILLS TAXONOMY & ROUTING

## 1. T0 MECHANICAL FORCING FUNCTION
Invariant: First tool call(s) in non-trivial technical turns MUST execute parallel `view_file` on `skills/<name>/SKILL.md` for ALL activated skills before output or code edits.

- C3 Diagnostics: `systematic-debugging`, `memory-leak-debugging`, `popperian-invariance-testing`
- C4 Tribunal: `gauntlet-loop`, `adversarial-tribunal`, `adversarial-sector-validation`, `permissioned-github`
- C5 UI & Kinetic: `modern-web-guidance`, `visual-synthesis-engine`, `interactive-kinetic-media-engine`, `a11y-debugging`

- C8 Swarm & Memory: `corporate-swarm-os`, `swarm-legacy-archaeology`, `project-neural-map`, `meta-skill-synthesis`, `autonomous-workspace-orchestration`, `google-antigravity-sdk`, `agy-customizations`, `antigravity-guide`, `technical-documentation-crafting`

## 3. EXHAUSTIVE 36-SKILL TRIGGER MATRIX

### C1: Inception & Prospecting
- `agi-prompt-refiner`: Short (<=200 chars), ambiguous, vague, or monosyllabic user prompts.
- `grill-me-layered`: Architecture trade-offs, scope alignment, interactive requirement gathering, `/grill-me`.
- `deep-planning-protocol`: Multi-module features, initial system design, `.planning/` docs, `/goal`.
- `technological-prospecting`: New libraries, external packages, benchmarking tools, SOTA tech evaluations.
- `systemic-insight-engine`: Holistic system modeling, domain reverse-engineering, cross-domain synthesis.

### C2: TDD, Refactor & Integration
- `test-driven-development`: Writing/modifying executable code, bug patching, unit/integration tests (Red-Green-Refactor).
- `master-refactoring-pipeline`: Code cleanup, modularization, cyclomatic complexity reduction, AST refactoring.
- `cross-sector-integration`: Connecting subsystems, API contracts, data wiring across module boundaries.

### C3: Diagnostics & Hardening
- `systematic-debugging`: Investigating runtime errors, exceptions, failing tests, causal 4-phase debugging.
- `memory-leak-debugging`: High memory/VRAM usage, OOM, heap snapshots, circular refs, listener leaks.
- `popperian-invariance-testing`: Complex math logic, tensors, physics engines, formal invariants, ghost data detection.

### C4: Tribunal & Governance
- `gauntlet-loop`: Pre-release stress test batteries, regression gauntlet, invariant verification suites.
- `adversarial-tribunal`: Red Team code review, formal quality audit (Q >= 9.0), critical decision gate.
- `adversarial-sector-validation`: Isolated stress validation of mission-critical subsystems and state engines.
- `permissioned-github`: Git ops, semantic commits, branching, PR creation, push/pull, releases.

### C5: UI, Kinetic & Modern Web
- `modern-web-guidance`: HTML/CSS/JS modern patterns, View Transitions, Popover API, Container Queries, `:has()`, UI styling.
- `visual-synthesis-engine`: Visual layout design, glassmorphism, color palettes, typographic contrast, UI mockups.
- `interactive-kinetic-media-engine`: CSS/JS animations, micro-interactions, spring physics, WebAudio telemetry.
- `a11y-debugging`: WCAG compliance, semantic tags, ARIA labels, focus traps, keyboard navigation, contrast.

### C6: Browser MCP & DevTools
- `chrome-devtools`: CDP/MCP debugging, live DOM inspection, network requests, console logs, profiling.
- `puppeteer-browser-automation`: End-to-end browser automation, synthetic user journeys, DOM scraping.
- `chrome-extensions`: Chrome Manifest V3 extensions, background service workers, content scripts, extension popup.
- `debug-optimize-lcp`: Core Web Vitals (LCP, INP, CLS), page load performance, rendering bottlenecks.

### C7: Multimodal & Spatial
- `omni-multimodal-spatial-engine`: 3D rendering, Three.js, WebGL, GLSL shaders, spatial math, raymarching.
- `sketchfab-prospecting-protocol`: Prospecting, downloading, validating, and converting 3D models (glTF/GLB/FBX).
- `youtube-audio-prospecting`: Audio telemetry extraction, yt-dlp, FFmpeg EBU R128 loudness normalization.
- `gemini-omni-video-generation`: Video synthesis, motion storyboard generation, video editing.

### C8: Swarm, SDK & Knowledge Base
- `corporate-swarm-os`: Subagent dispatch, multi-agent governance (<=12 files per cluster), handoff reports.
- `swarm-legacy-archaeology`: Legacy code reverse-engineering, unfamiliar repository excavation.
- `project-neural-map`: Mandatory update of `PROJECT_BRAIN.md` whenever >=3 files are modified or architecture shifts.
- `meta-skill-synthesis`: Creating or evolving skills and rules, meta-learning via `/learn`.
- `autonomous-workspace-orchestration`: Workspace lifecycle, multi-workspace isolation, branch sandboxing.
- `google-antigravity-sdk`: Development or orchestration with Google Antigravity Agent SDK.
- `agy-customizations`: Customizing Antigravity rules, skills, plugins, hooks, or MCP configurations.
- `antigravity-guide`: Antigravity CLI (`agy`), slash commands, IDE shortcuts, built-in features.
- `technical-documentation-crafting`: High-density technical writing, RFC specifications, architecture docs, READMEs.

## 4. COMPOSITE WORKFLOW PRESETS
- **Frontend / Web UI**: `modern-web-guidance` + `visual-synthesis-engine` + `a11y-debugging` + `interactive-kinetic-media-engine`
- **Code Change / Bug Fix**: `test-driven-development` + `systematic-debugging`
- **Multi-Module Refactor**: `master-refactoring-pipeline` + `cross-sector-integration` + `project-neural-map`
- **Math / Physics / Tensor Engine**: `test-driven-development` + `popperian-invariance-testing`
- **Subagent Delegation**: `corporate-swarm-os`
- **Milestone & Release Gate**: `gauntlet-loop` + `adversarial-tribunal` + `permissioned-github`
