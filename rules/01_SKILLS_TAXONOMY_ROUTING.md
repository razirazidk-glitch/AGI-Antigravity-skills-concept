# SKILLS TAXONOMY & ROUTING

## 1. T0 MECHANICAL FORCING FUNCTION
Invariant: First tool call(s) in non-trivial technical turns MUST execute parallel `view_file` on `skills/<name>/SKILL.md` for ALL activated skills before output or code edits.

## 2. 8 OPERATIONAL CLUSTERS
- C1 Inception: `deep-planning-protocol`, `grill-me-layered`, `agi-prompt-refiner`, `technological-prospecting`, `systemic-insight-engine`
- C2 TDD & Refactor: `test-driven-development`, `master-refactoring-pipeline`, `cross-sector-integration`
- C3 Diagnostics: `systematic-debugging`, `memory-leak-debugging`, `popperian-invariance-testing`
- C4 Tribunal: `gauntlet-loop`, `adversarial-tribunal`, `adversarial-sector-validation`, `permissioned-github`
- C5 UI & Kinetic: `modern-web-guidance`, `visual-synthesis-engine`, `interactive-kinetic-media-engine`, `a11y-debugging`
- C6 Browser MCP: `chrome-devtools`, `puppeteer-browser-automation`, `chrome-extensions`, `debug-optimize-lcp`
- C7 Multimodal: `omni-multimodal-spatial-engine`, `sketchfab-prospecting-protocol`, `youtube-audio-prospecting`, `gemini-omni-video-generation`
- C8 Swarm & Memory: `corporate-swarm-os`, `swarm-legacy-archaeology`, `project-neural-map`, `meta-skill-synthesis`, `autonomous-workspace-orchestration`, `google-antigravity-sdk`, `agy-customizations`, `antigravity-guide`, `technical-documentation-crafting`

## 3. TRIGGER MATRIX
- Ambiguous/short prompt (<=200 chars) -> `agi-prompt-refiner`
- Multi-module trade-offs -> `deep-planning-protocol` + `grill-me-layered`
- Code generation / bug fix -> `test-driven-development` (Red-Green-Refactor)
- New domain/library -> `technological-prospecting`
- Codebase refactor -> `master-refactoring-pipeline`
- Math/state logic -> `popperian-invariance-testing`
- Async/WebGL lifecycle -> `memory-leak-debugging`
- Web UI creation/edit -> `modern-web-guidance` + `a11y-debugging` + `visual-synthesis-engine`
- Audio assets -> `youtube-audio-prospecting`
- Video assets -> `gemini-omni-video-generation`
- 3D/GLSL -> `omni-multimodal-spatial-engine`
- API boundaries -> `cross-sector-integration`
- Multi-agent workflow -> `corporate-swarm-os`
- Milestone review -> `gauntlet-loop` + `adversarial-tribunal`
- >=3 files modified -> `project-neural-map` (update `PROJECT_BRAIN.md`)
