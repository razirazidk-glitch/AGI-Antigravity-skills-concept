# AGI LAYER 4: MULTIMODAL SPATIAL 3D, REAL AUDIO & MODERN WEB

> **Scope**: Layer 4 Specialized Operational Rule for `agi-antigravity-core`.
> **Mandate**: Authentic Physical Assets, AAA WebGL Optics, EBU R128 Audio, Chrome DevTools MCP.

---

## 1. 🎨 2D/3D ASSET GENERATION & OPTICAL RIGOR
- **2D Asset Synthesis (`generate_image`):** Specify sensor/optics (Arri/Hasselblad), volumetric lighting, and physical shaders. Strictly prohibit shallow buzzwords.
- **3D Procedural Mesh & GLSL:** Enforce IBL HDRI ambient lighting, metric bounding box normalization (`THREE.Box3`), and Ray-Box Interior Mapping shaders.

---

## 2. 🎵 ACOUSTIC PROSPECTING & SONIFICATION
- **Micro-Interactions (<50ms):** Synthesize via procedural WebAudio API oscillators.
- **Telemetry & Ambient Soundscapes:** Extract real authentic audio using `youtube-audio-prospecting` (`yt-dlp` + FFmpeg EBU R128 loudness normalization). Synthetic placeholder beeps are strictly prohibited.

---

## 3. 🌐 MODERN WEB STANDARDS & BROWSER AUTOMATION
- **Modern Web APIs:** Always prioritize View Transitions API, Popover API, CSS Container Queries, `:has()`, and WebAssembly.
- **Direct MCP Integration:** Leverage Chrome DevTools MCP (`take_screenshot`, `evaluate_script`, `get_console_message`) and Puppeteer MCP (`puppeteer_navigate`, `puppeteer_screenshot`) for deterministic live UI verification.

---

## 4. 🖥️ FULL HD VIEWPORT & 3-POINT VISUAL CRITIQUE MANDATE
When conducting browser automation, live UI verification, or screenshot audits:
- **Standard Viewport Rig:** Configure viewport explicitly to Full HD ($1920 \times 1080$) before visual capture to guarantee consistent rendering and responsive boundary testing.
- **3-Point Visual Critique Protocol:**
  1. **Layout Integrity:** Verify alignment, responsiveness, absence of horizontal scrollbar leakage, and zero clipped/overflowing elements.
  2. **Typography & Contrast:** Audit font hierarchy, line heights, font smoothing, and WCAG 2.2 AA color contrast ratios across dark/light themes.
  3. **Visual Hierarchy & Polish:** Inspect spatial depth, spacing consistency, micro-interactions, and high-fidelity visual balance.
